# Statmanets

منصة ذكية لإعداد القوائم المالية آليًا من ميزان المراجعة بصيغة Excel.

## المنصات

- **iPhone + Computer:** تطبيق ويب تقدمي PWA يعمل من المتصفح ويمكن تثبيته.
- **Android:** تطبيق APK مبني من نفس الكود باستخدام Capacitor.

## الفكرة الأساسية

يرفع المستخدم ملف ميزان المراجعة، ثم يقوم النظام بما يلي:

1. اكتشاف أعمدة رقم الحساب واسم الحساب والمدين والدائن أو الرصيد.
2. توحيد القيم والإشارات المحاسبية.
3. تصنيف الحسابات إلى بنود القوائم المالية، حتى عند اختلاف المسميات.
4. عرض الحسابات غير المؤكدة للمراجعة اليدوية.
5. إعداد قائمة المركز المالي وقائمة الدخل والتدفقات النقدية والتغيرات في حقوق الملكية.
6. حفظ خريطة الحسابات للشركة لاستخدامها لاحقًا.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## بناء نسخة الويب

```bash
npm run build
```

## إعداد Android

```bash
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

## مبدأ التصميم

لا يعتمد النظام على اسم ثابت للحساب. يستخدم قاموسًا متعدد اللغات، رقم الحساب، طبيعة الرصيد، قواعد محاسبية، ودرجة ثقة. يمكن للمستخدم تعديل أي تصنيف، ويتعلم ملف الشركة من التعديل للمرة التالية.
